# BookmarkHub--

A minimal browser extension for syncing bookmarks through a private GitHub Gist.

## Usage

1. Create a GitHub Token with Gists write permission.
2. Create a private Gist.
3. Enter the Token and Gist ID in the extension settings.
4. Upload or download bookmarks from the popup.

Bookmarks are stored in `bookmarkhub.json`. Downloading replaces local bookmarks, so keep a backup.
